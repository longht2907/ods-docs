# Desktop Client

## Desktop Client (Ứng dụng Máy tính)

**Desktop Client** là trái tim của trải nghiệm làm việc trên CloudFile. Nó biến hệ thống lưu trữ đám mây thành một thư mục thực sự trên máy tính của bạn, tích hợp sâu vào **Windows Explorer** (hoặc macOS Finder/Linux).

Thay vì phải liên tục truy cập trình duyệt web để tải file xuống rồi lại tải lên, Desktop Client cho phép bạn:

* **Làm việc như ổ cứng cục bộ:** Mở, chỉnh sửa và lưu file trực tiếp bằng các phần mềm quen thuộc (Word, Excel, Photoshop, AutoCAD...) mà không cần thay đổi thói quen.
* **Virtual Files (Tệp ảo):** Nhìn thấy toàn bộ hàng ngàn tệp tin của công ty nhưng **không tốn dung lượng ổ cứng** cho đến khi bạn thực sự mở chúng.
* **Menu chuột phải thông minh:** Chia sẻ file, khóa file hoặc tạo link gửi cho khách hàng ngay từ màn hình Desktop chỉ với một cú click chuột phải.

*Hãy chọn hệ điều hành của bạn ở menu bên dưới để xem hướng dẫn cài đặt chi tiết.*
