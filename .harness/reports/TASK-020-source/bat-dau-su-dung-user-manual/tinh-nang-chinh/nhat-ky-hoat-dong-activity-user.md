# Nhật ký Hoạt động (Activity User)

**Activity (Nhật ký hoạt động)** sẽ cho bạn biết mọi thứ đang diễn ra trên dữ liệu của mình theo thời gian thực.

## 1. Xem dòng sự kiện chung (All Activities)

Đây là nơi bạn cập nhật nhanh tình hình công việc mỗi buổi sáng.

{% stepper %}
{% step %}

### Mở Activity

Nhìn lên thanh menu trên cùng, nhấp vào biểu tượng **Sấm sét (Activity)** ⚡.
{% endstep %}

{% step %}

### Xem danh sách hoạt động

Một danh sách các hoạt động mới nhất sẽ hiện ra.
{% endstep %}

{% step %}

### Lọc kết quả

Sử dụng bộ lọc ở cột bên trái để xem chính xác những gì bạn cần:

* **Tất cả hoạt động (All activities):** Xem mọi thứ.
* **Bởi bạn (By you):** Xem lại lịch sử làm việc của chính mình.
* **Bởi người khác (By others):** Xem đồng nghiệp đang làm gì trên các thư mục chung.
* **Yêu thích (Favorites):** Chỉ xem hoạt động của các file bạn đã đánh dấu sao vàng ⭐.
  {% endstep %}
  {% endstepper %}

## 2. Kiểm tra lịch sử của một File cụ thể

Đây là tính năng hữu ích nhất khi bạn làm việc nhóm. Bạn muốn biết chính xác ai đã chỉnh sửa file Excel này vào lúc mấy giờ?

{% stepper %}
{% step %}

### Mở Files

Vào mục **Tệp tin (Files)**.
{% endstep %}

{% step %}

### Tìm file hoặc thư mục

Tìm đến file hoặc thư mục cần kiểm tra.
{% endstep %}

{% step %}

### Mở chi tiết

Nhấp vào dấu **Ba chấm (...)** -> Chọn **Chi tiết (Details)**.
{% endstep %}

{% step %}

### Xem tab Activity

Tại thanh bên phải (Sidebar), chuyển sang tab **Hoạt động (Activity)**.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Ví dụ thực tế:\
Bạn thấy một file bị thay đổi nội dung sai lệch. Mở tab Activity lên, bạn thấy dòng thông báo: "Nguyen Van A changed this file 2 hours ago". Bạn biết ngay cần liên hệ ai để trao đổi lại.
{% endhint %}

## 3. Nhận thông báo qua Email

Bạn muốn nhận email ngay lập tức khi Sếp upload file mới vào thư mục chung? Hãy cấu hình nhận thông báo:

{% stepper %}
{% step %}

### Mở cài đặt

Nhấp vào **Avatar** -> **Cài đặt (Settings)**.
{% endstep %}

{% step %}

### Chọn luồng hoạt động

Chọn mục **Luồng hoạt động (Activity)** ở cột trái.
{% endstep %}

{% step %}

### Chọn loại thông báo Email

Tích vào các ô vuông để chọn loại thông báo bạn muốn nhận qua Email:

* **A file or folder has been created:** Khi có file mới.
* **A file or folder has been changed:** Khi file bị sửa.
* **A file or folder has been deleted:** Khi file bị xóa.
  {% endstep %}

{% step %}

### Chọn tần suất gửi Email

Ở mục "Send emails", bạn có thể chọn tần suất:

* **Hourly:** Gom các thông báo lại gửi 1 tiếng/lần (Tránh spam mail).
* **Daily:** Gửi tổng hợp 1 lần vào cuối ngày.
  {% endstep %}
  {% endstepper %}
