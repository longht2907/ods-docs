# Online Office

Bạn cần sửa gấp báo giá nhưng máy tính đang dùng không cài Microsoft Word? Bạn muốn 3 người cùng nhập liệu vào một file Excel cùng lúc để kịp deadline?

Tính năng Office Collaboration tích hợp sẵn trong CloudFile sẽ giải quyết vấn đề đó.

## 1. Mở và Chỉnh sửa tài liệu

Hệ thống hỗ trợ chỉnh sửa trực tiếp các định dạng phổ biến của Microsoft Office:

* **Văn bản:** `.docx`, `.doc`, `.odt` (Tương tự Word).
* **Bảng tính:** `.xlsx`, `.xls`, `.ods` (Tương tự Excel).
* **Trình chiếu:** `.pptx`, `.ppt`, `.odp` (Tương tự PowerPoint).

{% stepper %}
{% step %}

### Mở file

Tại giao diện Tệp tin (Files), nhấp chuột trực tiếp vào tên file văn bản.
{% endstep %}

{% step %}

### Trình soạn thảo

Trình soạn thảo sẽ mở ra ngay trên trình duyệt web.
{% endstep %}

{% step %}

### Giao diện

Giao diện quen thuộc với các thanh công cụ (Home, Insert, Layout...) tương tự như phần mềm trên máy tính.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
💾 Lưu ý về Lưu tự động: Trong chế độ Online Office, bạn **không cần nhấn nút Save**. Hệ thống sẽ **tự động lưu** (Auto-save) mọi thay đổi của bạn sau mỗi vài giây. Hãy yên tâm tắt trình duyệt khi làm xong.
{% endhint %}

## 2. Tạo tài liệu mới

Bạn có thể soạn thảo văn bản mới ngay lập tức mà không cần upload từ máy tính.

{% stepper %}
{% step %}
Nhấp vào biểu tượng dấu **Cộng (+)** ở phía trên danh sách file.
{% endstep %}

{% step %}
Chọn loại tài liệu muốn tạo:

* 📄 **New Document** (Soạn thảo văn bản).
* 📊 **New Spreadsheet** (Bảng tính).
* 📽️ **New Presentation** (Trình chiếu).
  {% endstep %}

{% step %}
Đặt tên cho file và nhấn **Enter**.
{% endstep %}
{% endstepper %}

## 3. Cộng tác Thời gian thực (Co-authoring)

Đây là tính năng mạnh mẽ nhất của Văn phòng số. Nhiều người có thể cùng làm việc trên một file tại cùng một thời điểm.

**Kịch bản:** Bạn cần Sếp duyệt nội dung trong khi Kế toán điền số liệu.

{% stepper %}
{% step %}
**Chia sẻ file:** Gửi file cho đồng nghiệp (qua tính năng Chia sẻ).
{% endstep %}

{% step %}
**Cùng mở file:** Khi đồng nghiệp mở file đó lên, bạn sẽ thấy Avatar của họ xuất hiện ở góc trên bên phải.
{% endstep %}

{% step %}
**Thấy con trỏ chuột:** Bạn sẽ thấy con trỏ chuột của đồng nghiệp (có tên của họ) đang di chuyển và gõ chữ ở đâu.

* Mọi thay đổi hiển thị ngay lập tức (Real-time).
* Không còn cảnh gửi qua gửi lại 10 phiên bản file "Final\_v1", "Final\_v2" nữa.
  {% endstep %}
  {% endstepper %}

## 4. Chat và Bình luận (Sidebar)

Trong khi đang soạn thảo, bạn có thể trao đổi nhanh với đồng nghiệp ngay bên cạnh tài liệu mà không cần chuyển sang ứng dụng chat khác.

{% stepper %}
{% step %}
Trong giao diện soạn thảo, nhìn sang thanh bên phải (Sidebar).
{% endstep %}

{% step %}
Chuyển sang tab **Chat** hoặc **Comments**.
{% endstep %}

{% step %}
Để lại ghi chú cụ thể cho từng đoạn văn bản để đồng nghiệp sửa lại.
{% endstep %}
{% endstepper %}

## 5. Tương thích và Font chữ

* **Định dạng:** Hệ thống giữ nguyên định dạng file gốc. Bạn có thể tải file `.docx` về và mở bằng Microsoft Word trên máy tính bình thường.
* **Font chữ:** Hệ thống hỗ trợ các font Unicode phổ biến (Times New Roman, Arial, Roboto...).
