`POST` `/api/v1/resources`

API này cho phép khởi tạo một tài nguyên mới trong hệ thống. Yêu cầu gửi kèm Bearer Token xác thực trong tiêu đề HTTP `Authorization`.

## Bảng tham số

### Headers

| Tên header | Kiểu | Bắt buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `Authorization` | string | Có | Định dạng: `Bearer <token>` |
| `Content-Type` | string | Có | Phải là `application/json` |

### Body (JSON)

| Thuộc tính | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :--- | :--- | :--- | :--- |
| `name` | string | Có | Tên tài nguyên (tối đa 100 ký tự) |
| `type` | string | Có | Loại tài nguyên: `standard` hoặc `premium` |
| `description` | string | Không | Mô tả mục đích sử dụng |

## Ví dụ Request

```bash
curl -X POST "https://api.ods.vn/v1/resources" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "res-demo-01",
    "type": "standard",
    "description": "Tai nguyen thu nghiem"
  }'
```

## Ví dụ Response

```json
{
  "status": "success",
  "data": {
    "id": "res_987654321",
    "name": "res-demo-01",
    "type": "standard",
    "state": "provisioning",
    "created_at": "2026-09-16T08:00:00Z"
  }
}
```

## Bảng mã lỗi

| Mã HTTP | Mã lỗi nghiệp vụ | Nguyên nhân & Cách khắc phục |
| :--- | :--- | :--- |
| `400` | `INVALID_PAYLOAD` | Tham số gửi lên không đúng định dạng JSON hoặc thiếu trường bắt buộc. |
| `401` | `UNAUTHORIZED` | Token xác thực không hợp lệ hoặc đã hết hạn truy cập. |
| `409` | `RESOURCE_CONFLICT` | Tên tài nguyên đã tồn tại trong không gian tên hiện tại. |
| `500` | `INTERNAL_ERROR` | Lỗi nội bộ hệ thống trong quá trình khởi tạo tài nguyên. |
