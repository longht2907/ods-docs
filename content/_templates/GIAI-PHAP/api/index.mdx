Giao diện lập trình ứng dụng (REST API) cung cấp các phương thức chuẩn hóa để tương tác trực tiếp với nền tảng.

## Thông tin cơ bản

- **Base URL**: `https://api.ods.vn/v1`
- **Phương thức xác thực**: Bearer Token thông qua HTTP header `Authorization: Bearer <API_TOKEN>`
- **Định dạng dữ liệu**: `application/json`

## Danh sách Endpoint chính

| Phương thức | Endpoint | Mô tả |
| :--- | :--- | :--- |
| `GET` | `/status` | Kiểm tra trạng thái hoạt động của dịch vụ |
| `POST` | `/tasks` | Khởi tạo tác vụ xử lý dữ liệu mới |
| `GET` | `/tasks/{id}` | Lấy thông tin chi tiết và kết quả tác vụ |
