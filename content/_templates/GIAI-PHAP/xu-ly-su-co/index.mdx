description: "Hướng dẫn chẩn đoán nguyên nhân và biện pháp khắc phục các sự cố kỹ thuật thường gặp."

Trang này tổng hợp các tình huống lỗi phổ biến khi vận hành giải pháp và quy trình xử lý tiêu chuẩn.

## Bảng sự cố thường gặp

| Hiện tượng | Nguyên nhân khả dĩ | Hướng xử lý |
| :--- | :--- | :--- |
| Không kết nối được API | Token hết hạn hoặc sai endpoint | Kiểm tra lại cấu hình và cấp mới API token |
| Phản hồi chậm (> 5s) | Quá tải lưu lượng hoặc nghẽn mạng nội bộ | Kiểm tra tài nguyên và liên hệ hỗ trợ kỹ thuật |
| Lỗi dữ liệu không hợp lệ | Payload sai schema | Đối chiếu định dạng payload với tài liệu API |

## Hỗ trợ kỹ thuật

Nếu sự cố vẫn tiếp diễn sau khi thực hiện các bước trên, vui lòng liên hệ bộ phận hỗ trợ kỹ thuật 24/7 của ODS để được hỗ trợ trực tiếp.
