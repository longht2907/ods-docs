    <ApiEndpoint method="POST" url="https://apiai.cloudfone.vn/api/Audio/DeleteAudio" />

    Xóa một tệp âm thanh ghi âm hoặc tệp TTS khỏi kho lưu trữ của doanh nghiệp khi không còn sử dụng trong chiến dịch nào.

    ## Tham số request

    | Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
    | :-- | :-- | :-: | :-- |
    | `ServiceCode` | string | Có | Mã dịch vụ Autocall (ví dụ: `CF-XXXXX`). |
    | `AuthUser` | string | Có | Mã tài khoản khách hàng. |
    | `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
    | `Id` | number | Có | Mã ID của tệp âm thanh cần xóa (ví dụ: `41`). |
  </ApiReferenceMain>

    ## Cấu trúc phản hồi

    ### Bảng mô tả trường

    | Trường | Kiểu dữ liệu | Mô tả |
    | :-- | :-- | :-- |
    | `result` | string | Trạng thái thực thi (`success` hoặc `failed`). |
    | `message` | string | Thông báo phản hồi từ hệ thống. |

    ## Lưu ý quan trọng

    <Callout type="warning">
    - **Ràng buộc chiến dịch**: Không thể xóa tệp âm thanh nếu tệp này đang được sử dụng trong một chiến dịch Autocall đang chờ hoặc đang chạy. Hãy kiểm tra các chiến dịch trước khi thực hiện xóa.
    - **Tính bất biến**: Hành động xóa là vĩnh viễn và không thể phục hồi tệp âm thanh sau khi đã xóa.
    </Callout>

    ## Lỗi thường gặp

    <Accordions>
      <Accordion title="400 Bad Request / result: failed">
        - Sai thông tin xác thực `AuthUser` hoặc `AuthKey`.
        - Mã `Id` tệp âm thanh không tồn tại.
        - Tệp âm thanh đang bị ràng buộc bởi chiến dịch chưa hoàn tất.
      </Accordion>
    </Accordions>
