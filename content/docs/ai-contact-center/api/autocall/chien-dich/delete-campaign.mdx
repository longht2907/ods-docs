---

<Callout type="info">`POST` `{AUTOCALL_BASE_URL}/api/Autocall/DeleteCampaign`</Callout>

Xóa một chiến dịch gọi tự động không còn sử dụng hoặc hủy một chiến dịch đang chờ kích hoạt.

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceCode` | string | Có | Mã dịch vụ Autocall (ví dụ: `CF-XXXXX`). |
| `AuthUser` | string | Có | Mã tài khoản khách hàng. |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `Id` | string | Có | Mã UUID định danh của chiến dịch cần xóa. |

## Ví dụ request

<Tabs items={['cURL', 'JavaScript', 'Python']}>
  <Tab value="cURL">
```bash
curl -X POST "{AUTOCALL_BASE_URL}/api/Autocall/DeleteCampaign" \
  -H "Content-Type: application/json" \
  -d '{
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Id": "a8f192b0-4b7e-41a2-9bc3-xxxxxxxxxxxx"
  }'
```
  </Tab>
  <Tab value="JavaScript">
```javascript
const response = await fetch('{AUTOCALL_BASE_URL}/api/Autocall/DeleteCampaign', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },

```
  </Tab>
  <Tab value="Python">
```python
import requests

payload = {
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Id": "a8f192b0-4b7e-41a2-9bc3-xxxxxxxxxxxx",

    "{AUTOCALL_BASE_URL}/api/Autocall/DeleteCampaign",
    json=payload,
    headers={"Content-Type": "application/json"},
    timeout=15,

print(response.json())
```

## Response mẫu

```json
{
  "result": "success",
  "message": ""
}
```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `result` | string | Trạng thái thực thi (`success` hoặc `failed`). |
| `message` | string | Thông báo kết quả từ máy chủ. |

## Lưu ý quan trọng

<Callout type="warning">
- **Tính bất biến**: Hành động xóa chiến dịch là không thể hoàn tác. Mọi lịch sử và cấu hình kịch bản gắn liền với chiến dịch sẽ bị xóa.
- **Trạng thái chiến dịch**: Chỉ nên xóa các chiến dịch ở trạng thái đang chờ kích hoạt hoặc đã hoàn tất. Tránh xóa chiến dịch đang trong tiến trình quay số (`Status: 1`).
</Callout>

## Lỗi thường gặp

<Accordions>
  <Accordion title="400 Bad Request / result: failed">
    - Sai thông tin xác thực `AuthUser` hoặc `AuthKey`.
    - Mã định danh `Id` không tồn tại hoặc sai định dạng UUID.
  </Accordion>
</Accordions>
