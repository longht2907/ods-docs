    <ApiEndpoint method="POST" url="https://apiai.cloudfone.vn/api/Autocall/GetCampaignDetail" />

    Tra cứu toàn bộ thông số cấu hình của một chiến dịch gọi tự động bao gồm tệp âm thanh áp dụng, nhóm danh bạ, thời gian chạy và kịch bản phím bấm IVR.

    ## Tham số request

    | Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
    | :-- | :-- | :-: | :-- |
    | `ServiceCode` | string | Có | Mã dịch vụ Autocall (ví dụ: `CF-XXXXX`). |
    | `AuthUser` | string | Có | Mã tài khoản khách hàng. |
    | `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
    | `Id` | string | Có | Mã UUID định danh của chiến dịch cần xem chi tiết. |
  </ApiReferenceMain>

    ## Cấu trúc phản hồi

    | Trường | Kiểu dữ liệu | Mô tả |
    | :-- | :-- | :-- |
    | `result` | string | Trạng thái xử lý (`success` hoặc `failed`). |
    | `data` | array | Mảng chứa dữ liệu chi tiết cấu hình của chiến dịch. |
    | `data[].campaignId` | string | Mã định danh duy nhất của chiến dịch. |
    | `data[].campaignName` | string | Tên chiến dịch. |
    | `data[].contactId` | number | ID nhóm danh bạ áp dụng cho chiến dịch. |
    | `data[].trunk` | string | Đầu số Trunk gọi ra. |
    | `data[].timeStartCall` | string | Thời gian lên lịch kích hoạt gọi. |
    | `data[].status` | number | Trạng thái: `0` (đang chờ), `1` (đang chạy), `2` (đã chạy xong). |

    ## Lỗi thường gặp

    <Accordions>
      <Accordion title="400 Bad Request / result: failed">
        - Sai thông tin xác thực `AuthUser` hoặc `AuthKey`.
        - `Id` chiến dịch không tồn tại hoặc sai định dạng UUID.
