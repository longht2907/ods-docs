<Callout type="info">`POST` `{AUTOCALL_BASE_URL}/api/Contact/AddContact`</Callout>

Thêm mới thông tin một khách hàng vào cơ sở dữ liệu danh bạ Autocall để phục vụ các chiến dịch gọi tự động.

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceCode` | string | Có | Mã dịch vụ Autocall (ví dụ: `CF-XXXXX`). |
| `AuthUser` | string | Có | Mã tài khoản khách hàng. |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `Phone` | string | Có | Số điện thoại của khách hàng (ví dụ: `0900000000`). |
| `Contact_Name` | string | Không | Tên gợi nhớ định danh liên hệ. |
| `First_Name` | string | Không | Tên của khách hàng. |
| `Last_Name` | string | Không | Họ và tên đệm. |
| `Email_Address` | string | Không | Địa chỉ Email. |
| `Company` | string | Không | Tên công ty/doanh nghiệp. |
| `Department` | string | Không | Phòng ban/chức vụ. |
| `Address` | string | Không | Địa chỉ liên hệ. |
| `Web_Site` | string | Không | Website của khách hàng. |

## Ví dụ request

<Tabs items={['cURL', 'JavaScript', 'Python']}>
  <Tab value="cURL">
```bash
curl -X POST "{AUTOCALL_BASE_URL}/api/Contact/AddContact" \
  -H "Content-Type: application/json" \
  -d '{
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",

    "Contact_Name": "Nguyen Van A",
    "First_Name": "A",
    "Last_Name": "Nguyen Van",
    "Email_Address": "nguyenvana@example.com",
    "Company": "ODS JSC",
    "Address": "TP. Ho Chi Minh"
  }'
```

  <Tab value="Python">
```python
import requests

payload = {
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Phone": "0900000000",
    "Contact_Name": "Nguyen Van A",
}
response = requests.post(
    "{AUTOCALL_BASE_URL}/api/Contact/AddContact",
    json=payload,
    headers={"Content-Type": "application/json"},
    timeout=15,
)
print(response.json())
```

## Response mẫu

```json
{
  "result": "success",
  "message": "",
  "data": 1052
}
```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `result` | string | Trạng thái xử lý (`success` hoặc `failed`). |
| `data` | number | Mã `ContactId` của khách hàng vừa tạo (dùng để thêm vào nhóm). |

## Lưu ý quan trọng

<Callout type="info">
- **Định dạng số điện thoại**: Trường `Phone` phải là chuỗi số hợp lệ (ví dụ: `0900000000` hoặc `84900000000`), không chứa dấu chấm, khoảng trắng hay ký tự gạch nối.
- **Quy trình gán nhóm**: Tạo liên hệ xong hệ thống trả về mã `data` (chính là `ContactId`). Bạn cần tiếp tục gọi API [AddContactToGroup](/docs/ai-contact-center/api/autocall/danh-ba/add-contact-to-group) để gán liên hệ này vào nhóm chiến dịch.
</Callout>

## Lỗi thường gặp

<Accordions>
  <Accordion title="400 Bad Request / result: failed">
    - Sai thông tin xác thực `AuthUser` hoặc `AuthKey`.
    - Thiếu số điện thoại bắt buộc `Phone`.
    - Số điện thoại sai định dạng viễn thông.
  </Accordion>
</Accordions>
