<Callout type="info">`POST` `{AUTOCALL_BASE_URL}/api/Contact/GetContactGroupList`</Callout>

Lấy danh sách các nhóm danh bạ hiện có, hỗ trợ phân trang và tìm kiếm theo tên nhóm.

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceCode` | string | Có | Mã dịch vụ Autocall (ví dụ: `CF-XXXXX`). |
| `AuthUser` | string | Có | Mã tài khoản khách hàng. |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `Key` | string | Không | Từ khóa tìm kiếm theo tên nhóm danh bạ. |
| `PageIndex` | number | Không | Số thứ tự trang hiện tại (mặc định là `1`). |
| `PageSize` | number | Không | Số lượng bản ghi trên một trang (mặc định là `20`). |

## Ví dụ request

<Tabs items={['cURL', 'JavaScript', 'Python']}>
  <Tab value="cURL">
```bash
curl -X POST "{AUTOCALL_BASE_URL}/api/Contact/GetContactGroupList" \
  -H "Content-Type: application/json" \
  -d '{
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Key": "",
    "PageIndex": 1,
    "PageSize": 20
  }'
```
  </Tab>
  <Tab value="JavaScript">
```javascript
const response = await fetch('{AUTOCALL_BASE_URL}/api/Contact/GetContactGroupList', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    ServiceCode: 'YOUR_SERVICE_CODE',
    AuthUser: 'YOUR_AUTH_USER',
    AuthKey: 'YOUR_AUTH_KEY',
    PageIndex: 1,
    PageSize: 20,
  }),
});
const data = await response.json();
console.log(data);
```
  </Tab>
  <Tab value="Python">
```python
import requests

payload = {
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "PageIndex": 1,
    "PageSize": 20,
}
response = requests.post(
    "{AUTOCALL_BASE_URL}/api/Contact/GetContactGroupList",
    json=payload,
    headers={"Content-Type": "application/json"},
    timeout=15,
)
print(response.json())
```
  </Tab>
</Tabs>

## Response mẫu

```json
{
  "result": "success",
  "message": "",
  "total": 3,
  "data": [
    {
      "contactGroupId": 1006,
      "contactGroupName": "Khach hang VIP Thang 10",
      "totalContacts": 150,
      "createdDate": "2026-10-13 08:30:00"
    }
  ]
}
```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `result` | string | Trạng thái xử lý (`success` hoặc `failed`). |
| `total` | number | Tổng số lượng nhóm danh bạ tìm thấy. |
| `data` | array | Danh sách thông tin chi tiết từng nhóm danh bạ. |
| `data[].contactGroupId` | number | Mã ID của nhóm danh bạ (dùng cho chiến dịch). |
| `data[].contactGroupName` | string | Tên của nhóm danh bạ. |
| `data[].totalContacts` | number | Tổng số lượng số điện thoại hiện có trong nhóm. |
| `data[].createdDate` | string | Thời điểm tạo nhóm. |

## Lưu ý quan trọng

<Callout type="info">
- **Tra cứu ID nhóm**: Dùng endpoint này để tìm nhanh mã `contactGroupId` trước khi cấu hình vào tham số `ContactID` trong API [StartCampaign](/docs/ai-contact-center/api/autocall/chien-dich/start-campaign).
- **Phân trang**: Sử dụng `PageIndex` và `PageSize` để duyệt toàn bộ danh sách khi có nhiều nhóm danh bạ.
</Callout>

## Lỗi thường gặp

<Accordions>
  <Accordion title="400 Bad Request / result: failed">
    - Sai thông tin xác thực `AuthUser` hoặc `AuthKey`.
    - Dịch vụ `ServiceCode` không hợp lệ.
  </Accordion>
  <Accordion title="Danh sách data rỗng []">
    - Doanh nghiệp chưa tạo nhóm danh bạ nào, hoặc từ khóa tìm kiếm `Key` không khớp với tên nhóm nào.
  </Accordion>
</Accordions>
