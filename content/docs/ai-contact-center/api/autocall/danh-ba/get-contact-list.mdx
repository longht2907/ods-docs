<Callout type="info">`POST` `{AUTOCALL_BASE_URL}/api/Contact/GetContactList`</Callout>

Lấy toàn bộ danh sách khách hàng đã được nhập vào hệ thống Autocall (không giới hạn theo nhóm), hỗ trợ tìm kiếm theo số điện thoại, tên hoặc phân trang.

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceCode` | string | Có | Mã dịch vụ Autocall (ví dụ: `CF-XXXXX`). |
| `AuthUser` | string | Có | Mã tài khoản khách hàng. |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `Key` | string | Không | Từ khóa tìm kiếm theo tên hoặc số điện thoại. |
| `PageIndex` | number | Không | Số thứ tự trang hiện tại (mặc định là `1`). |
| `PageSize` | number | Không | Số lượng bản ghi trên một trang (mặc định là `20`). |

## Ví dụ request

<Tabs items={['cURL', 'JavaScript', 'Python']}>
  <Tab value="cURL">
```bash
curl -X POST "{AUTOCALL_BASE_URL}/api/Contact/GetContactList" \
  -H "Content-Type: application/json" \
  -d '{
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Key": "",
    "PageIndex": 1,
    "PageSize": 20
  }'
```
  </Tab>
  <Tab value="JavaScript">
```javascript
const response = await fetch('{AUTOCALL_BASE_URL}/api/Contact/GetContactList', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    ServiceCode: 'YOUR_SERVICE_CODE',
    AuthUser: 'YOUR_AUTH_USER',
    AuthKey: 'YOUR_AUTH_KEY',
    PageIndex: 1,
    PageSize: 20,
  }),
});
const data = await response.json();
console.log(data);
```
  </Tab>
  <Tab value="Python">
```python
import requests

payload = {
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "PageIndex": 1,
    "PageSize": 20,
}
response = requests.post(
    "{AUTOCALL_BASE_URL}/api/Contact/GetContactList",
    json=payload,
    headers={"Content-Type": "application/json"},
    timeout=15,
)
print(response.json())
```
  </Tab>
</Tabs>

## Response mẫu

```json
{
  "result": "success",
  "message": "",
  "total": 520,
  "data": [
    {
      "contactId": 1052,
      "phone": "0900000000",
      "contactName": "Nguyen Van A",
      "company": "ODS JSC",
      "address": "TP. Ho Chi Minh"
    }
  ]
}
```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `result` | string | Trạng thái xử lý (`success` hoặc `failed`). |
| `total` | number | Tổng số lượng liên hệ tìm thấy. |
| `data` | array | Danh sách thông tin chi tiết từng liên hệ. |
| `data[].contactId` | number | Mã định danh duy nhất của liên hệ. |
| `data[].phone` | string | Số điện thoại khách hàng. |
| `data[].contactName` | string | Tên định danh của liên hệ. |
| `data[].company` | string | Tên công ty / tổ chức. |
| `data[].address` | string | Địa chỉ của khách hàng. |

## Lưu ý quan trọng

<Callout type="info">
- **Quản lý danh bạ tổng**: Endpoint này giúp bạn tra cứu toàn bộ danh bạ khách hàng đã từng nhập vào hệ thống Autocall, độc lập với việc liên hệ đó có được gán vào nhóm hay không.
- **Phân trang**: Sử dụng `PageIndex` và `PageSize` để duyệt danh bạ quy mô lớn.
</Callout>

## Lỗi thường gặp

<Accordions>
  <Accordion title="400 Bad Request / result: failed">
    - Sai thông tin xác thực `AuthUser` hoặc `AuthKey`.
    - Dịch vụ `ServiceCode` không hợp lệ.
  </Accordion>
  <Accordion title="Danh sách data rỗng []">
    - Chưa có liên hệ nào được thêm vào hệ thống qua API [AddContact](/docs/ai-contact-center/api/autocall/danh-ba/add-contact).
  </Accordion>
</Accordions>
