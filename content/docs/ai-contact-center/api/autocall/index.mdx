description: "Khung tài liệu API tích hợp chiến dịch gọi tự động."
---

Không gian này dành cho API tích hợp chiến dịch Autocall từ hệ thống bên ngoài. REST path, request fields và response schema sẽ được bổ sung sau khi có đặc tả kỹ thuật được duyệt.

Trong thời gian chờ đặc tả API, xem [hướng dẫn Gọi tự động trên Portal](/docs/ai-contact-center/user-guider-portal/10-goi-tu-dong) để nắm quy trình vận hành tổng thể.
