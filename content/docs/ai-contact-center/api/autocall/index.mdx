API Autocall cung cấp bộ công cụ lập trình mạnh mẽ giúp doanh nghiệp tự động hóa các chiến dịch gọi điện thoại hàng loạt phục vụ chăm sóc khách hàng, thông báo nhắc nợ, khảo sát ý kiến hoặc gửi mã xác thực tự động (Voice OTP).

<Callout type="info">
  **Base URL Autocall chính thức:** `https://apiai.cloudfone.vn`
  Mọi endpoint đều sử dụng phương thức `POST` với dữ liệu định dạng `application/json`.
</Callout>

## Quy trình 4 bước triển khai chiến dịch

Để tạo và vận hành một chiến dịch gọi tự động thông qua API, hệ thống tuân theo quy trình tuần tự:

<Steps>
  <Step>
    ### Tạo tệp âm thanh phát thoại
    Sử dụng API [Tạo âm thanh TTS](/docs/ai-contact-center/api/autocall/am-thanh/create-tts-audio) để chuyển đổi nội dung văn bản thành giọng đọc tự nhiên (Google, FPT, Vbee, Viettel) hoặc tải tệp âm thanh ghi âm sẵn dạng chuỗi Base64. Lấy mã `AudioId` trả về.
  </Step>
  <Step>
    ### Tạo nhóm liên hệ và nhập danh bạ khách hàng
    - Tạo nhóm khách hàng bằng API [Tạo nhóm danh bạ](/docs/ai-contact-center/api/autocall/danh-ba/add-contact-group) để lấy `ContactGroupID`.
    - Thêm danh sách số điện thoại qua API [Thêm danh bạ](/docs/ai-contact-center/api/autocall/danh-ba/add-contact) và gán vào nhóm bằng API [Thêm danh bạ vào nhóm](/docs/ai-contact-center/api/autocall/danh-ba/add-contact-to-group).
  </Step>
  <Step>
    ### Khởi tạo và thiết lập chiến dịch
    Gọi API [Khởi chạy chiến dịch](/docs/ai-contact-center/api/autocall/chien-dich/start-campaign), liên kết `ContactGroupID`, tệp âm thanh `Audios`, cấu hình hành động khi bấm phím `Keypress` và thời gian bắt đầu gọi `TimeStartCall`.
  </Step>
  <Step>
    ### Giám sát tiến độ và lấy báo cáo
    Sử dụng API [Báo cáo chiến dịch](/docs/ai-contact-center/api/autocall/chien-dich/get-campaign-report) để theo dõi tỷ lệ kết nối thành công, số lượng cuộc gọi không bắt máy hoặc bận theo thời gian thực.
  </Step>
</Steps>
