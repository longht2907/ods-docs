Chào mừng bạn đến với tài liệu kỹ thuật tích hợp **ODS AI Contact Center**. Hệ thống cung cấp nền tảng API toàn diện giúp doanh nghiệp kết nối tổng đài thoại thông minh vào các ứng dụng nội bộ như CRM, ERP, Helpdesk, hệ thống quản lý bán hàng hoặc website.

<Callout type="info">
  **Domain tích hợp chính thức:**
  - API Tổng đài PBX: `https://api.ods.vn`
  - API Chiến dịch Autocall: `https://apiai.cloudfone.vn`
  - *Lưu ý tương thích:* Hệ thống vẫn hỗ trợ các domain cũ (`api.cloudfone.vn`, `api.matbao.one`) cho các đối tác đã tích hợp trước đó, nhưng khuyến nghị chuyển đổi sang `https://api.ods.vn`.
</Callout>

## Quy trình tích hợp nhanh

Để kết nối ứng dụng của bạn với ODS AI Contact Center, hãy thực hiện theo 3 bước cơ bản:

<Steps>
  <Step>
    ### Lấy thông tin xác thực API
    Đăng nhập vào Portal quản trị tổng đài, truy cập mục **Cấu hình API** để lấy bộ 3 khóa: `ServiceName` (Mã dịch vụ), `AuthUser` (Mã khách hàng) và `AuthKey` (API Key bí mật).
  </Step>
  <Step>
    ### Lựa chọn giao thức kết nối
    - **Gọi ra nhanh từ CRM**: Sử dụng [Click-to-Call](/docs/ai-contact-center/api/tong-dai/cuoc-goi/click-to-call) để kích hoạt cuộc gọi tới máy nhánh nhân viên.
    - **Hiển thị thông tin khách gọi đến**: Cấu hình URL nhận [Popup Webhook](/docs/ai-contact-center/api/webhook/popup).
    - **Thoại trực tiếp không cần cài app**: Tích hợp [WebRTC qua WSS](/docs/ai-contact-center/api/websocket-rtc/ket-noi-webrtc).
    - **CSKH / Nhắc nợ tự động**: Sử dụng [Chiến dịch Autocall](/docs/ai-contact-center/api/autocall).
  </Step>
  <Step>
    ### Kiểm thử và triển khai
    Thực thi request với các ví dụ code mẫu cURL, JavaScript hoặc Python đi kèm trong từng trang tài liệu endpoint.
  </Step>
</Steps>
