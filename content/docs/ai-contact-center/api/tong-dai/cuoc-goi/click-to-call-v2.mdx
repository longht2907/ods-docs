<Callout type="info">`POST` `{BASE_URL}/api/CloudFone/AutoCallV2`</Callout>

API thực thi cuộc gọi tự động đảo hướng: Hệ thống sẽ quay số gọi đến khách hàng trước. Khi khách hàng nhấc máy, cuộc gọi sẽ được chuyển tiếp vào hướng đích định tuyến trước (Inbound Route hoặc IVR/Hàng đợi) đã thiết lập trên tổng đài.

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceName` | string | Có | Mã dịch vụ tổng đài khi mua tại ODS (ví dụ: `CF-BS0XXXX`). |
| `AuthUser` | string | Có | Mã tài khoản khách hàng (ví dụ: `ODSXXXX`). |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `Ext` | string | Có | Tên Inbound Route đã cấu hình trên trang quản trị tổng đài (ví dụ: `C2C-WebSite`). |
| `PhoneNumber` | string | Có | Định dạng `<Tên_đầu_số_hoặc_Trunk>/<Số_điện_thoại_khách>` (ví dụ: `02873007788/0900000000`). |
| `KeySearch` | string | Không | Mã định danh cuộc gọi (khuyến nghị GUID). Nếu không truyền, hệ thống sẽ tự sinh ngẫu nhiên. |

## Ví dụ request

<Tabs items={['cURL', 'JavaScript', 'Python']}>
  <Tab value="cURL">
```bash
curl -X POST "{BASE_URL}/api/CloudFone/AutoCallV2" \
  -H "Content-Type: application/json" \
  -d '{
    "ServiceName": "YOUR_SERVICE_NAME",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Ext": "C2C-WebSite",
    "PhoneNumber": "02873007788/0900000000",
    "KeySearch": "1b38fbda-4b7e-41a2-9bc3-xxxxxxxxxxxx"
  }'
```

  <Tab value="Python">
```python
import requests

payload = {
    "ServiceName": "YOUR_SERVICE_NAME",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Ext": "C2C-WebSite",
    "PhoneNumber": "02873007788/0900000000",
    "KeySearch": "1b38fbda-4b7e-41a2-9bc3-xxxxxxxxxxxx",
}
response = requests.post(
    "{BASE_URL}/api/CloudFone/AutoCallV2",
    json=payload,
    headers={"Content-Type": "application/json"},
    timeout=15,
)
print(response.json())
```

## Response mẫu

```json
{
  "result": "success",
  "message": "GỌI TỰ ĐỘNG THÀNH CÔNG",
  "keySearch": "1b38fbda-4b7e-41a2-9bc3-xxxxxxxxxxxx"
}
```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `result` | string | Trạng thái thực thi (`success` hoặc `failed`). |
| `message` | string | Thông báo kết quả từ tổng đài. |
| `keySearch` | string | Mã định danh cuộc gọi trả về. |

## Lưu ý quan trọng
- Tham số `Ext` ở endpoint này là **Tên Inbound Route** đã được tạo sẵn trên Portal ODS, không phải số máy nhánh thông thường.
- Định dạng `PhoneNumber` bắt buộc phải có dấu gạch chéo `/` phân tách giữa đầu số gọi ra và số điện thoại người nhận.
