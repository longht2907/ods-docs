---
title: "API Tổng đài PBX"
description: "Tổng quan các API quản lý số nội bộ, khởi tạo cuộc gọi và truy xuất lịch sử tổng đài ODS."
---

Nhóm API Tổng đài PBX cho phép các hệ thống phần mềm doanh nghiệp (CRM, ERP, HRM, thương mại điện tử) tương tác trực tiếp với tổng đài điện thoại ODS: quản trị máy nhánh nhân viên, điều khiển cuộc gọi ra, quản lý danh bạ khách hàng, thiết lập định tuyến thông minh và tra cứu nhật ký đàm thoại.

<Callout type="info">
  **Base URL chính thức:** `https://api.ods.vn`
  Mọi request đều sử dụng phương thức `POST` với phần thân `application/json`.
</Callout>
