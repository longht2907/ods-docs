<Callout type="info">`POST` `{BASE_URL}/api/CloudFone/GetCallHistoryVer2`</Callout>

Phiên bản nâng cấp của `GetCallHistory`, chuyển đổi toàn bộ tên trường dữ liệu trả về sang chuẩn tiếng Anh camelCase (`callDate`, `callerNumber`, `receiveNumber`, `totalCallTime`, `realCallTime`).

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceName` | string | Có | Mã dịch vụ tổng đài khi mua tại ODS. |
| `AuthUser` | string | Có | Mã tài khoản khách hàng. |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `TypeGet` | number | Có | Loại cuộc gọi: `0` (tất cả), `1` (gọi đến), `2` (gọi đi), `3` (gọi nội bộ), `4` (gọi nhỡ), `5` (nhóm trả lời), `6` (nhóm nhỡ), `7` (tất cả cuộc nhỡ). |
| `DateStart` | string | Có | Thời gian bắt đầu tra cứu (`YYYY-MM-DD HH:mm:ss`). |
| `DateEnd` | string | Có | Thời gian kết thúc tra cứu (`YYYY-MM-DD HH:mm:ss`). |
| `PageIndex` | number | Có | Số thứ tự trang bắt đầu từ `1`. |
| `PageSize` | number | Có | Số bản ghi trên 1 trang (tối đa `200`). |
| `HideFWOut` | number | Không | `1` để gom các cuộc gọi forward về 1 dòng khi lấy all log. |
| `IsSort` | number | Không | `0` (tăng dần - mặc định), `1` (giảm dần). |
| `CallNum` | string | Không | Lọc theo số gọi. |
| `ReceiveNum` | string | Không | Lọc theo số nhận. |
| `Key` | string | Không | Mã định danh cuộc gọi. |

```json
      "headNumber": "02873007788",
      "receiveNumber": "0900000000",
      "status": "ANSWERED",

      "linkFile": "https://recording.ods.vn/recordings/audio.mp3",
      "gsmPort": "",

```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `key` | string | Mã cuộc gọi định danh. |
| `callDate` | string | Thời gian thực hiện cuộc gọi. |
| `callerNumber` | string | Số gọi đi. |
| `callerName` | string | Tên người gọi. |
| `headNumber` | string | Đầu số Hotline tổng đài. |
| `receiveNumber` | string | Số nhận cuộc gọi. |
| `status` | string | Trạng thái (`ANSWERED`, `NO ANSWER`, `BUSY`). |
| `totalCallTime` | string | Tổng thời gian cuộc gọi (giây). |
| `realCallTime` | string | Thời gian đàm thoại thực tế (giây). |
| `linkFile` | string | Đường dẫn tệp ghi âm. |
| `typecall` | string | Hướng cuộc gọi (`Inbound`, `Outbound`). |

## Lưu ý quan trọng
- Endpoint này chuẩn hóa tên trường tiếng Anh cho `GetCallHistory`, hỗ trợ tốt hơn cho việc tích hợp trên các framework hiện đại.
- Giới hạn phân trang tối đa `PageSize` là 200 bản ghi.

## Lỗi thường gặp

<Accordions>
  <Accordion title="Khoảng thời gian tra cứu quá dài">
    Nên giới hạn khoảng cách giữa `DateStart` và `DateEnd` trong vòng 31 ngày.
  </Accordion>
  <Accordion title="Dữ liệu rỗng khi tra cứu">
    Kiểm tra xem `TypeGet` đã chọn đúng loại cuộc gọi mong muốn (`0` là tất cả, `1` là gọi đến, `2` là gọi đi).
