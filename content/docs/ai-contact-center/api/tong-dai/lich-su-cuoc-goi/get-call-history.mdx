  <ApiReferenceMain>
    <ApiEndpoint method="POST" url="https://api.ods.vn/api/CloudFone/GetCallHistory" />

    <Callout type="warning">
      **Khuyến nghị:** Dữ liệu trả về theo cấu trúc tiếng Việt cũ (`ngayGoi`, `soGoiDen`, `thoiGianThucGoi`). Doanh nghiệp được khuyến nghị sử dụng [GetCallLogs](/docs/ai-contact-center/api/tong-dai/lich-su-cuoc-goi/get-call-logs) để có định dạng dữ liệu chuẩn hóa và đầy đủ thông tin nhất.
    </Callout>

    ## Tham số request

    | Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
    | :-- | :-- | :-: | :-- |
    | `ServiceName` | string | Có | Mã dịch vụ tổng đài khi mua tại ODS. |
    | `AuthUser` | string | Có | Mã tài khoản khách hàng. |
    | `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
    | `TypeGet` | string / number | Có | Loại cuộc gọi: `0` (tất cả), `1` (gọi đến), `2` (gọi đi), `3` (gọi nội bộ), `4` (gọi nhỡ), `5` (nhóm trả lời), `6` (nhóm nhỡ), `7` (tất cả cuộc nhỡ). |
    | `DateStart` | string | Có | Thời gian bắt đầu (ví dụ: `2026-10-13 00:00:01`). |
    | `DateEnd` | string | Có | Thời gian kết thúc (ví dụ: `2026-10-13 23:59:59`). |
    | `PageIndex` | number | Có | Số thứ tự trang bắt đầu từ `1`. |
    | `PageSize` | number | Có | Số bản ghi trên 1 trang (tối đa `200`). |
    | `HideFWOut` | number | Không | `1` để gom các cuộc gọi chuyển tiếp (forward) về 1 dòng khi lấy tất cả log. |
    | `IsSort` | number | Không | `0` (sắp xếp tăng dần - mặc định), `1` (sắp xếp giảm dần). |
    | `CallNum` | string | Không | Lọc theo số gọi. |
    | `ReceiveNum` | string | Không | Lọc theo số nhận. |
    | `Key` | string | Không | Mã cuộc gọi (nhận từ Webhook Popup hoặc KeySearch). |
  </ApiReferenceMain>

    ## Cấu trúc phản hồi

    | Trường | Kiểu dữ liệu | Mô tả |
    | :-- | :-- | :-- |
    | `stt` | number | Số thứ tự dòng trên trang kết quả. |
    | `key` | string | Mã định danh cuộc gọi. |
    | `ngayGoi` | string | Thời gian phát sinh cuộc gọi. |
    | `soGoiDen` | string | Số điện thoại nguồn gọi đến. |
    | `dauSo` | string | Đầu số Hotline tổng đài. |
    | `soNhan` | string | Số nhận cuộc gọi (máy nhánh hoặc nhóm). |
    | `trangThai` | string | Trạng thái (`ANSWERED`, `NO ANSWER`, `BUSY`). |
    | `tongThoiGianGoi` | string | Tổng thời gian cuộc gọi (định dạng `mm:ss`). |
    | `thoiGianThucGoi` | string | Thời gian đàm thoại thực tế (tính bằng giây). |
    | `linkFile` | string | Link tải tệp ghi âm. |
    | `typecall` | string | Loại cuộc gọi (`Inbound`, `Outbound`). |

    ## Lưu ý quan trọng
    - Dữ liệu trả về sử dụng cấu trúc trường tiếng Việt cũ. Khuyến nghị các ứng dụng tích hợp mới sử dụng [GetCallLogs](/docs/ai-contact-center/api/tong-dai/lich-su-cuoc-goi/get-call-logs).
    - Giới hạn phân trang tối đa `PageSize` là 200 bản ghi.

    ## Lỗi thường gặp

    <Accordions>
      <Accordion title="Khoảng thời gian tra cứu quá dài">
