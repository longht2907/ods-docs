<Callout type="info">`POST` `{BASE_URL}/api/CloudFone/GetCallLogs`</Callout>

API lấy danh sách nhật ký cuộc gọi (CDR) phiên bản mới nhất trên tổng đài ODS, hỗ trợ đầy đủ chi tiết thời gian đổ chuông, thời lượng đàm thoại thực tế, thông tin máy nhánh chuyển hướng và liên kết tải tệp ghi âm.

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceName` | string | Có | Mã dịch vụ tổng đài khi mua tại ODS (ví dụ: `CF-BSXXXX`). |
| `AuthUser` | string | Có | Mã tài khoản khách hàng (ví dụ: `ODSXXXX`). |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `Direction` | string | Có | Hướng cuộc gọi: `"all"` (tất cả), `"Inbound"` (gọi vào), `"Outbound"` (gọi ra), `"Local"` (nội bộ). |
| `DateStart` | string | Có | Thời gian bắt đầu tra cứu (định dạng `YYYY-MM-DD HH:mm:ss` hoặc `YYYY-MM-DD`). |
| `DateEnd` | string | Có | Thời gian kết thúc tra cứu (định dạng `YYYY-MM-DD HH:mm:ss`). |
| `PageIndex` | number | Có | Số thứ tự trang bắt đầu từ `0` hoặc `1`. |
| `PageSize` | number | Có | Số lượng bản ghi trên một trang (tối đa `200`). |
| `Disposition` | string | Không | Trạng thái: `"ANSWERED"` (nghe máy), `"NO ANSWER"` (không nghe), `"BUSY"` (bận), `"FAILED"` (thất bại), `"ANSWERED_ELSEWHERE"`, `"Cancel"`. |
| `IsSort` | number | Không | Sắp xếp thời gian: `0` (tăng dần - mặc định), `1` (giảm dần). |
| `CallNum` | string | Không | Lọc theo số gọi (Source). |
| `ReceiveNum` | string | Không | Lọc theo số nhận (Destination). |
| `Trunk` / `trunk` | string | Không | Lọc theo đầu số Hotline tổng đài (DID). |
| `Key` | string | Không | Mã định danh cuộc gọi hoặc `KeySearch`. |

<Callout type="info">
  **Chi tiết các trạng thái `Disposition`:**
  - `ANSWERED`: Cuộc gọi kết nối thành công, có đàm thoại.
  - `NO ANSWER`: Đổ chuông nhưng người nhận không bắt máy.
  - `BUSY`: Máy bận hoặc người nhận chủ động từ chối cuộc gọi.
  - `FAILED`: Không thể thiết lập cuộc gọi (lỗi định tuyến hoặc sự cố mạng).
  - `ANSWERED_ELSEWHERE`: Cuộc gọi đã được nghe máy ở thiết bị/máy nhánh khác. Xảy ra khi cấu hình đổ chuông nhóm theo cơ chế `ringall` (tất cả cùng reo, 1 người nhấc máy thì các máy còn lại sẽ ghi nhận trạng thái này), hoặc khi 1 tài khoản máy nhánh đăng ký trên nhiều thiết bị đồng thời (hỗ trợ tối đa 3 thiết bị).
  - `Cancel`: Người gọi hủy cuộc gọi trước khi có người bắt máy.
</Callout>

## Ví dụ request

<Tabs items={['cURL', 'JavaScript', 'Python']}>
  <Tab value="cURL">
```bash
curl -X POST "{BASE_URL}/api/CloudFone/GetCallLogs" \
  -H "Content-Type: application/json" \
  -d '{
    "ServiceName": "YOUR_SERVICE_NAME",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Direction": "all",
    "Disposition": "",
    "DateStart": "2026-10-13 00:00:00",
    "DateEnd": "2026-10-13 23:59:59",
    "IsSort": 1,
    "CallNum": "",
    "ReceiveNum": "",
    "trunk": "",
    "Key": "",
    "PageIndex": 1,
    "PageSize": 20
  }'
```
  </Tab>
  <Tab value="JavaScript">
```javascript
const response = await fetch('{BASE_URL}/api/CloudFone/GetCallLogs', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    ServiceName: 'YOUR_SERVICE_NAME',
    AuthUser: 'YOUR_AUTH_USER',
    AuthKey: 'YOUR_AUTH_KEY',
    Direction: 'all',
    DateStart: '2026-10-13 00:00:00',
    DateEnd: '2026-10-13 23:59:59',
    IsSort: 1,
    PageIndex: 1,
    PageSize: 20,
  }),
});
const data = await response.json();
console.log(data);
```
  </Tab>
  <Tab value="Python">
```python
import requests

payload = {
    "ServiceName": "YOUR_SERVICE_NAME",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "Direction": "all",
    "DateStart": "2026-10-13 00:00:00",
    "DateEnd": "2026-10-13 23:59:59",
    "IsSort": 1,
    "PageIndex": 1,
    "PageSize": 20,
}
response = requests.post(
    "{BASE_URL}/api/CloudFone/GetCallLogs",
    json=payload,
    headers={"Content-Type": "application/json"},
    timeout=15,
)
print(response.json())
```
  </Tab>
</Tabs>

```json
{
  "result": "success",
  "message": "",
  "total": 1,
  "data": [
    {
      "linkedId": "1651213743.261649",
      "timeCall": "2026-10-13T13:29:03",
      "recordingFile": "https://recording.ods.vn/recordings/audio.mp3",
      "direction": "Outbound",
      "src": "101",
      "srcName": "Support Team 1",
      "did": "02873007788",
      "queue": "",
      "dst": "0900000000",
      "disposition": "ANSWERED",
      "billsecAgent": "120",
      "duration": "135",
      "transfered": null,
      "followmeTo": "",
      "pickupExt": "",
      "dialUExtAnswer": "5",
      "hotlineUExtAnswer": "5",
      "billsecTelco": "120",
      "event": "finish"
    }
  ]

```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `linkedId` | string | Mã định danh duy nhất của cuộc gọi trên tổng đài. |
| `timeCall` | string | Thời điểm phát sinh cuộc gọi (định dạng ISO 8601). |
| `recordingFile` | string | Đường dẫn trực tiếp để nghe hoặc tải tệp ghi âm cuộc gọi. |
| `direction` | string | Hướng cuộc gọi (`Inbound`, `Outbound`, `Local`). |
| `src` | string | Số gọi đi (Source - số máy nhánh hoặc số khách hàng). |
| `srcName` | string | Tên người gọi (lấy theo danh bạ nếu có). |
| `dst` | string | Số nhận cuộc gọi (Destination). |
| `did` | string | Đầu số Hotline tổng đài tiếp nhận hoặc gọi ra. |
| `queue` | string | Tên hoặc số nhóm tiếp nhận cuộc gọi (nếu đi qua hàng đợi). |
| `disposition` | string | Trạng thái kết nối cuộc gọi (`ANSWERED`, `NO ANSWER`, `BUSY`, v.v.). |
| `billsecAgent` | string | Thời gian đàm thoại thực tế của nhân viên (tính bằng giây). |
| `duration` | string | Tổng thời gian cuộc gọi từ lúc đổ chuông đến khi gác máy (giây). |
| `billsecTelco` | string | Thời gian tính cước thực tế với nhà mạng viễn thông (giây). |
| `transfered` | string / null | Số máy nhánh được chuyển cuộc gọi đến (đối với cuộc gọi chuyển hướng Transfer). |
| `followmeTo` | string | Số máy nhánh hoặc số điện thoại chuyển tiếp cuộc gọi (Follow me). |
| `pickupExt` | string | Số máy nhánh đã thực hiện rước cuộc gọi (Call Pickup). |
| `dialUExtAnswer` | string | Thời gian chờ nghe máy của riêng số máy nhánh (giây). |
| `hotlineUExtAnswer` | string | Tổng thời gian chờ nghe máy của cuộc gọi từ đầu đến cuối (giây). |
| `event` | string | Sự kiện cuộc gọi (`hide` hoặc `finish`). |


## Lưu ý quan trọng
- Khuyến nghị sử dụng API này thay cho các API lịch sử cũ (`GetCallHistory`) để nhận đầy đủ link ghi âm và dữ liệu đàm thoại chi tiết.
- Giới hạn `PageSize` tối đa là 200 bản ghi mỗi lần gọi.
