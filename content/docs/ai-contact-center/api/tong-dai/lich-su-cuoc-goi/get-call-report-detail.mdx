<Callout type="info">`POST` `{BASE_URL}/api/CloudFone/GetCallReportDetail`</Callout>

Lấy thông tin chi tiết từng cuộc gọi của một số máy nhánh cụ thể, lọc theo số sao đánh giá (từ 1 đến 5 sao) hoặc trạng thái cuộc gọi.

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceCode` | string | Có | Mã dịch vụ tổng đài khi mua tại ODS (ví dụ: `CF-BS0xxxxxxx`). |
| `AuthUser` | string | Có | Mã tài khoản khách hàng. |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `Extension` | string | Có | Số máy nhánh cần tra cứu (ví dụ: `101`). |
| `TypeGet` | number | Có | Bộ lọc đánh giá: `1`–`5` (cuộc gọi được đánh giá 1–5 sao), `6` (không trả lời), `7` (bận), `8` (bị chặn), `9` (không kết nối được), `10` (không đánh giá). |
| `TypeCall` | number | Có | Hướng cuộc gọi: `1` (cuộc gọi vào - Inbound), `2` (cuộc gọi ra - Outbound). |
| `DateStart` | string | Có | Thời gian bắt đầu tra cứu (`YYYY-MM-DD HH:mm:ss`). |
| `DateEnd` | string | Có | Thời gian kết thúc tra cứu (`YYYY-MM-DD HH:mm:ss`). |
| `PageIndex` | number | Có | Số thứ tự trang bắt đầu từ `1`. |
| `PageSize` | number | Có | Số bản ghi trên 1 trang (tối đa `200`). |

```python
    }
```


| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `stt` | number | Số thứ tự bản ghi trong danh sách kết quả. |
| `calldate` | string | Thời điểm bắt đầu cuộc gọi (`YYYY-MM-DDTHH:mm:ss`). |
| `clid` | string | Chuỗi Caller ID đầy đủ gồm tên và số máy gọi đi. |
| `callerNumber` | string | Số điện thoại người gọi đến. |
| `callerName` | string | Tên người gọi (nếu có lưu trong danh bạ tổng đài). |
| `did` | string | Đầu số Hotline tiếp nhận cuộc gọi vào. |
| `src` | string | Nguồn cuộc gọi (số gọi đi hoặc số máy nhánh). |
| `dst` | string | Đích đến của cuộc gọi (số máy nhánh hoặc số điện thoại khách hàng). |
| `duration` | string | Tổng thời gian kết nối bao gồm cả thời gian đổ chuông (tính bằng giây). |
| `billsec` | string | Thời gian đàm thoại thực tế tính cước (tính bằng giây). |
| `disposition` | string | Trạng thái kết thúc cuộc gọi (ví dụ: `ANSWERED`, `NO ANSWER`, `BUSY`). |
| `uniqueid` | string | Mã định danh duy nhất của cuộc gọi trong hệ thống Asterisk tổng đài. |
| `recordingfile` | string | Đường dẫn URL file ghi âm cuộc gọi (nếu máy nhánh có bật ghi âm). |
| `key_press` | string | Phím bấm đánh giá chất lượng dịch vụ của khách hàng (`1` đến `5`). |

## Lưu ý quan trọng

<Callout type="warning">
- **Định dạng thời gian**: Nếu chỉ truyền ngày vào `DateStart` (ví dụ `2026-10-01`), hệ thống sẽ tự động hiểu là `2026-10-01 00:00:00`.
- **Phân trang dữ liệu**: Tham số `PageSize` hỗ trợ tối đa **200** bản ghi trên mỗi trang. Khi tổng số cuộc gọi (`total`) vượt quá 200, cần tăng `PageIndex` để lấy tiếp.
- **Tính năng phím bấm đánh giá**: Endpoint này chỉ trả về dữ liệu có `key_press` khi kịch bản cuộc gọi Inbound/Outbound có kích hoạt module IVR xin đánh giá sao sau khi kết thúc đàm thoại.
</Callout>

## Lỗi thường gặp

<Accordions>
  <Accordion title="400 Bad Request / result: failed">
    - Sai thông tin xác thực `AuthUser` hoặc `AuthKey`.
    - `ServiceCode` không hợp lệ hoặc đã hết hạn dịch vụ.
    - Thiếu hoặc sai định dạng `DateStart` / `DateEnd`.
  </Accordion>
  <Accordion title="data trả về rỗng []">
    - Máy nhánh `Extension` không phát sinh cuộc gọi nào trong khoảng thời gian tra cứu.
    - `TypeGet` chọn loại đánh giá không có dữ liệu thực tế (ví dụ chọn 5 sao nhưng trong kỳ không có cuộc gọi nào đạt 5 sao).
  </Accordion>
</Accordions>
