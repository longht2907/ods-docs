<Callout type="info">`POST` `{BASE_URL}/api/CloudFone/GetCallReport`</Callout>

Lấy thông tin báo cáo đánh giá chất lượng cuộc gọi tổng hợp của tất cả các số máy nhánh trên tổng đài (tính năng khách hàng bấm phím đánh giá từ 1 đến 5 sao sau khi kết thúc cuộc gọi).

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceCode` | string | Có | Mã dịch vụ tổng đài khi mua tại ODS (ví dụ: `CF-BS0XXXX`). *(Lưu ý: Tên trường là `ServiceCode`)*. |
| `AuthUser` | string | Có | Mã tài khoản khách hàng (ví dụ: `ODSXXXX`). |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `TypeGet` | number | Có | Hướng cuộc gọi: `0` (tất cả cuộc gọi), `1` (cuộc gọi đến - Inbound), `2` (cuộc gọi đi - Outbound). |
| `DateStart` | string | Có | Thời gian bắt đầu tra cứu (`YYYY-MM-DD HH:mm:ss`). |
| `DateEnd` | string | Có | Thời gian kết thúc tra cứu (`YYYY-MM-DD HH:mm:ss`). |
| `PageIndex` | number | Có | Số thứ tự trang bắt đầu từ `1`. |
| `PageSize` | number | Có | Số bản ghi trên 1 trang (tối đa `200`). |

## Ví dụ request

<Tabs items={['cURL', 'JavaScript', 'Python']}>
  <Tab value="cURL">
```bash
curl -X POST "{BASE_URL}/api/CloudFone/GetCallReport" \

  -d '{
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "TypeGet": 0,
    "DateStart": "2026-10-01 00:00:00",
    "DateEnd": "2026-10-13 23:59:59",
    "PageIndex": 1,
    "PageSize": 20
  }'
```

```python
import requests

payload = {
    "ServiceCode": "YOUR_SERVICE_CODE",
    "AuthUser": "YOUR_AUTH_USER",
    "AuthKey": "YOUR_AUTH_KEY",
    "TypeGet": 0,
    "DateStart": "2026-10-01 00:00:00",
    "DateEnd": "2026-10-13 23:59:59",
    "PageIndex": 1,
    "PageSize": 20,
}
response = requests.post(
    "{BASE_URL}/api/CloudFone/GetCallReport",
    json=payload,
    headers={"Content-Type": "application/json"},
    timeout=15,
)
print(response.json())
```

## Response mẫu

```json
{
  "result": "success",
  "message": "",
  "total": 1,
  "data": [
    {
      "stt": 1,
      "staff": "101/NguyenVanA(Call out)",
      "totalCall": "17",
      "noanswer": "3",
      "answer": "9",
      "busy": "1",
      "blacklist": "0",
      "cantconnect": "4",
      "rate1": "0",
      "rate2": "0",
      "rate3": "0",
      "rate4": "1",
      "rate5": "8",
      "norate": "0",
      "total": 17
    }
  ]
}
```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `staff` | string | Số máy nhánh và tên nhân viên (kèm chú thích `Call out` hoặc `Call in`). |
| `totalCall` | string | Tổng số cuộc gọi của máy nhánh này. |
| `answer` | string | Số cuộc gọi trả lời thành công. |
| `noanswer` | string | Số cuộc gọi không trả lời. |
| `busy` | string | Số cuộc gọi bận. |
| `blacklist` | string | Số cuộc gọi nằm trong danh sách đen (bị chặn). |
| `cantconnect` | string | Số cuộc gọi không thể kết nối được. |
| `rate1` - `rate5` | string | Số lượng cuộc gọi được khách hàng đánh giá tương ứng từ 1 sao đến 5 sao. |
| `norate` | string | Số cuộc gọi khách hàng không thực hiện bấm phím đánh giá. |
| `total` | number | Tổng số lượng bản ghi thỏa mãn điều kiện lọc. |

## Lưu ý quan trọng
- Trường tham số định danh dịch vụ trong payload JSON bắt buộc là **`ServiceCode`** (không phải `ServiceName`).
- Tính năng đánh giá sao yêu cầu kịch bản IVR sau cuộc gọi (Post-call Survey) đã được kích hoạt trên Portal.

## Lỗi thường gặp

<Accordions>
  <Accordion title="Các trường đánh giá rate1-rate5 đều trả về 0">
    Kiểm tra xem kịch bản cuộc gọi đã bật tính năng cho khách hàng bấm phím đánh giá sau khi gác máy hay chưa.
  </Accordion>
  <Accordion title="Sai tên trường ServiceCode">
    Đảm bảo gửi trường `ServiceCode` trong body JSON theo đúng đặc tả của endpoint này.
  </Accordion>
