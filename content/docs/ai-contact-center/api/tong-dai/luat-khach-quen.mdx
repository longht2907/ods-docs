<Callout type="info">`POST` `{BASE_URL}/api/CloudFone/CreateAndUpdateFamiliar`</Callout>

Tính năng Luật khách quen (Sticky Agent) cho phép hệ thống tự động ghi nhớ và ưu tiên đổ chuông trực tiếp tới máy nhánh của nhân viên phụ trách khi khách hàng gọi vào số Hotline của tổng đài.

**Nguyên tắc hoạt động:**
- Khi có cuộc gọi đến Inbound, nếu số điện thoại (`Phone`) khớp trong danh sách: tổng đài sẽ ưu tiên đổ chuông thẳng tới máy nhánh (`Extention`) tương ứng thay vì đi qua menu IVR thông thường.
- Một số điện thoại khách hàng có thể được ánh xạ vào nhiều đầu số Hotline (`Inbound`).
- Hỗ trợ xử lý hàng loạt bản ghi thông qua mảng `Items`.

## Tham số request

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả chi tiết |
| :-- | :-- | :-: | :-- |
| `ServiceName` | string | Có | Mã dịch vụ tổng đài khi mua tại ODS (ví dụ: `CF-BS0XXX`). |
| `AuthUser` | string | Có | Mã tài khoản khách hàng (ví dụ: `ODSXXXX`). |
| `AuthKey` | string | Có | Khóa bí mật API do ODS cấp. |
| `Type` | string | Có | Thao tác thực hiện: `"insert"` (thêm mới), `"update"` (cập nhật) hoặc `"delete"` (xóa khỏi danh sách). |
| `Items` | array | Có | Mảng danh sách các bản ghi khách hàng cần xử lý. |

### Cấu trúc từng phần tử trong `Items`

| Thuộc tính | Kiểu dữ liệu | Bắt buộc | Mô tả |
| :-- | :-- | :-: | :-- |
| `Inbound` | string | Có | Đầu số Hotline tổng đài cần áp dụng luật (ví dụ: `02873070809`). |
| `Extention` | string | Có | Số máy nhánh của nhân viên sẽ nhận cuộc gọi (ví dụ: `998`, `5000`). *(Lưu ý: Giữ nguyên tên trường `Extention` có chữ 't')*. |
| `Phone` | string | Có | Số điện thoại của khách hàng cần định danh (ví dụ: `0900000000`). |

## Response mẫu

```json
{
  "result": "success",
  "message": "Xử lý thành công 1/1 bản ghi.",
  "data": [
    {
      "serviceName": "CF-BS0000085",
      "type": "insert",
      "inbound": "02873070809",
      "extention": "998",
      "phone": "0900000000",
      "result": "success",
      "message": "Xử lý thành công.",
      "data": "last"
    }
  ]
}
```

| Trường | Kiểu dữ liệu | Mô tả |
| :-- | :-- | :-- |
| `result` | string | Trạng thái xử lý chung của toàn bộ request (`success` hoặc `failed`). |
| `message` | string | Thông báo tổng quan số lượng bản ghi đã xử lý. |
| `data` | array | Danh sách kết quả chi tiết từng phần tử trong `Items`. |
| `data[].result` | string | Trạng thái xử lý của riêng bản ghi đó (`success` hoặc `failed`). |
| `data[].message` | string | Thông báo chi tiết cho từng bản ghi (ví dụ: "Xử lý thành công", "Số điện thoại đã tồn tại"). |

## Lưu ý quan trọng
- Tên trường trong mảng `Items` là **`Extention`** (viết bằng chữ `t`), không phải `Extension`. Vui lòng giữ đúng cú pháp để hệ thống nhận diện.

## Lỗi thường gặp

<Accordions>
  <Accordion title="Số điện thoại đã tồn tại khi insert">
