Khi tích hợp tính năng thoại của ODS AI Contact Center vào phần mềm quản lý quan hệ khách hàng (CRM) hoặc ERP, doanh nghiệp có thể lựa chọn một trong hai kiến trúc triển khai chính:

## So sánh hai phương thức tích hợp

| Tiêu chí | 1. Softphone / IP Phone + API | 2. WebRTC trên trình duyệt |
| :-- | :-- | :-- |
| **Cơ chế hoạt động** | Sử dụng [Click-to-Call](/docs/ai-contact-center/api/tong-dai/cuoc-goi/click-to-call) để kích hoạt cuộc gọi về thiết bị ngoài và nhận sự kiện qua [Popup Webhook](/docs/ai-contact-center/api/webhook/popup). | Đăng ký trực tiếp tài khoản SIP vào tổng đài thông qua giao thức SIP over Secure WebSocket (WSS). |
| **Thiết bị client** | Bắt buộc nhân viên phải cài Softphone (Zoiper, MicroSIP) hoặc dùng máy điện thoại IP Phone vật lý. | Hoạt động trực tiếp trên trình duyệt web (Chrome, Edge, Firefox, Safari) thông qua mic/tai nghe của máy tính. |
| **Trải nghiệm người dùng** | Khi click "Gọi", thiết bị Softphone đổ chuông trước, nhân viên nhấc máy rồi hệ thống mới quay số khách hàng. | Nhấn "Gọi" là hệ thống quay số ngay lập tức trên giao diện web, giao diện bàn phím quay số hiển thị trực tiếp trong CRM. |
| **Độ phức tạp tích hợp** | **Thấp**: Chỉ cần gửi HTTP POST request và nhận Webhook. | **Trung bình - Cao**: Cần xây dựng module SIP client trên Frontend (hoặc nhúng Widget có sẵn). |
| **Độ ổn định** | Rất cao, phụ thuộc vào chất lượng phần cứng và mạng chuyên dụng. | Rất tốt trên các trình duyệt hiện đại hỗ trợ đầy đủ WebRTC. |
