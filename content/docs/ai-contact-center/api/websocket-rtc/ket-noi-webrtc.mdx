WebRTC (Web Real-Time Communication) cho phép trình duyệt web thiết lập kênh truyền âm thanh hai chiều trực tiếp với tổng đài ODS thông qua giao thức SIP over Secure WebSocket (WSS).

<Callout type="info">
  **Thông số kết nối máy chủ WSS:**
  - WebSocket Server: `wss://rtc.ods.vn:8089/ws` **(Cần bổ sung: [Q5])**
  - SIP Domain / Realm: `sip.ods.vn` **(Cần bổ sung: [Q5])**
  - Giao thức âm thanh hỗ trợ: Opus, PCMA (G.711a), PCMU (G.711u)
</Callout>

## Quy trình tích hợp bằng JsSIP

[JsSIP](https://jssip.net/) là thư viện JavaScript SIP Client chuẩn mực và phổ biến nhất hiện nay để kết nối WebRTC với tổng đài Asterisk / FreePBX.

### 1. Cài đặt thư viện

Cài đặt thông qua npm hoặc tải từ CDN:

```bash
npm install jssip
```

Hoặc nhúng qua thẻ `<script>`:

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/jssip/3.10.1/jssip.min.js"></script>
```

### 2. Khởi tạo SIP User Agent (UA)

```javascript
import JsSIP from 'jssip';

// Cấu hình thông tin máy nhánh nhân viên
const socket = new JsSIP.WebSocketInterface('wss://rtc.ods.vn:8089/ws');

const configuration = {
  sockets: [socket],
  uri: 'sip:101@sip.ods.vn',
  password: 'YOUR_EXTENSION_PASSWORD',
  display_name: 'Nguyen Van A',
};

const ua = new JsSIP.UA(configuration);

// Bắt các sự kiện vòng đời kết nối
ua.on('connected', () => console.log('WSS Connected'));
ua.on('disconnected', () => console.warn('WSS Disconnected'));
ua.on('registered', () => console.log('SIP Registered thành công!'));
ua.on('registrationFailed', (e) => console.error('SIP Register thất bại:', e.cause));

// Lắng nghe cuộc gọi đến
ua.on('newRTCSession', (data) => {
  const session = data.session;

  if (session.direction === 'incoming') {
    console.log('Cuộc gọi đến từ:', session.remote_identity.uri.user);

    // Bắt sự kiện khi cuộc gọi được kết nối để gắn audio stream
    session.on('peerconnection', (e) => {
      e.peerconnection.addEventListener('track', (trackEvent) => {
        const remoteAudio = document.getElementById('remoteAudio');
        remoteAudio.srcObject = trackEvent.streams[0];
        remoteAudio.play();
      });
    });

    // Chấp nhận nghe máy khi người dùng nhấn nút Nghe
    // session.answer({ mediaConstraints: { audio: true, video: false } });
  }
});

// Bắt đầu đăng ký
ua.start();
```

### 3. Thực hiện cuộc gọi ra (Outgoing Call)

```javascript
// Gọi ra đến số điện thoại khách hàng
const targetNumber = '0900000000';

const eventHandlers = {
  progress: () => console.log('Đang đổ chuông...'),
  failed: (e) => console.error('Cuộc gọi thất bại:', e.cause),
  ended: () => console.log('Cuộc gọi kết thúc'),
  confirmed: () => console.log('Khách hàng đã nhấc máy!'),
};

const options = {
  eventHandlers: eventHandlers,
  mediaConstraints: { audio: true, video: false },
};

const session = ua.call(`sip:${targetNumber}@sip.ods.vn`, options);

// Gắn luồng âm thanh nghe tiếng khách hàng
session.on('peerconnection', (e) => {
  e.peerconnection.addEventListener('track', (trackEvent) => {
    const remoteAudio = document.getElementById('remoteAudio');
    remoteAudio.srcObject = trackEvent.streams[0];
    remoteAudio.play();
  });
});
```

## Yêu cầu môi trường & Quyền trình duyệt

- **HTTPS Bắt buộc**: Trình duyệt chỉ cho phép truy cập Micro (`getUserMedia`) trên các website chạy giao thức `https://` (hoặc `http://localhost` khi thử nghiệm nội bộ).
- Cần có thẻ HTML audio để phát âm thanh ra loa/tai nghe:
  ```html
  <audio id="remoteAudio" autoplay></audio>
  ```

## Thư viện & Demo tham khảo

ODS hỗ trợ kết nối SIP qua WSS theo chuẩn Asterisk WebRTC. Bạn có thể tham khảo thêm các thư viện mã nguồn mở và giao diện mẫu:

- [JsSIP Documentation](https://jssip.net/): Tài liệu hướng dẫn chính thức của thư viện JsSIP.
- [SIP.js](https://sipjs.com/): Thư viện JavaScript SIP phổ biến cho WebRTC.
- [Browser-Phone Asterisk WebRTC](https://github.com/InnovateAsterisk/Browser-Phone): Giao diện Softphone WebRTC mẫu chạy trên nền Asterisk.
- [ctxSip Client](https://collecttix.github.io/ctxSip/): Bộ giao diện web phone hoàn chỉnh viết bằng HTML/JS.
