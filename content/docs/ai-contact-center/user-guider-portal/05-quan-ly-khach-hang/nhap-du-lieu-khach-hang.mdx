Hệ thống hỗ trợ hai cách để thêm mới khách hàng:

* **Thêm thủ công** – Nhập thông tin từng khách hàng một cách thủ công.
* **Nhập danh sách từ file Excel** – Tải lên danh sách khách hàng hàng loạt.

## 1. Thêm khách hàng thủ công

**Bước 1: Mở giao diện thêm khách hàng**

Ở giao diện **Khách hàng Tiềm năng** hoặc **Khách hàng Hiện tại**, nhấn vào nút "Thêm mới khách hàng" (góc trên bên phải, màu xanh).

![](/media/ai-contact-center/user-guider-portal/img-IhtzQ3VWCnNIjJ3lE5JZ.png)

**Bước 2: Nhập thông tin khách hàng**

Một cửa sổ mới xuất hiện, nhập các thông tin:

* Tên khách hàng
* Số điện thoại
* Email (nếu có)
* Ghi chú (thông tin bổ sung về khách hàng)
* Gán nhãn khách hàng (ví dụ: Khách VIP, Đang quan tâm, Đã chốt đơn, v.v.)
* Chọn danh sách tổ chức (nếu khách thuộc một tổ chức cụ thể)

![](/media/ai-contact-center/user-guider-portal/img-qnxtBFfLQn8PBBk3zm2a.png)

**Bước 3: Lưu thông tin**

Sau khi nhập đủ thông tin, nhấn nút "Lưu" để hoàn tất.

Khách hàng sẽ xuất hiện trong danh sách tương ứng.

## 2. Nhập danh sách khách hàng từ file Excel

**Bước 1: Tải file mẫu Excel**

Nhấn vào nút "Download file excel mẫu" (màu vàng) để tải file mẫu về máy tính.

![](/media/ai-contact-center/user-guider-portal/img-rrNMh7XPKgp97GpJip0h.png)

**Bước 2: Nhập danh sách khách hàng vào file Excel**

Mở file Excel vừa tải xuống.

Điền đầy đủ thông tin khách hàng vào các cột tương ứng như: **Tên khách hàng, Số điện thoại, Email, Ghi chú, Nhãn khách hàng**.

Lưu lại file sau khi nhập xong.

**Bước 3: Tải lên danh sách khách hàng**

Nhấn vào nút "Nhập dữ liệu từ Excel" (màu xanh).

Chọn file Excel đã điền thông tin.

Hệ thống sẽ tự động nhập danh sách khách hàng vào hệ thống.

![](/media/ai-contact-center/user-guider-portal/img-3F7GjtchzUv87xgLrMYn.png)

**Bước 4: Kiểm tra dữ liệu sau khi nhập**

Sau khi tải lên thành công, danh sách khách hàng sẽ xuất hiện trong hệ thống.

Nếu có sai sót, có thể chỉnh sửa thông tin bằng cách nhấn vào biểu tượng Chỉnh sửa (✏️).

<Callout type="warn">
**Lưu ý:**

✔️ Nếu nhập thủ công, hãy đảm bảo không bỏ trống các thông tin quan trọng như **Số điện thoại**.

✔️ Khi tải danh sách từ Excel, cần điền đúng định dạng của hệ thống để tránh lỗi nhập liệu.

✔️ Hệ thống cho phép lọc, tìm kiếm khách hàng bằng từ khóa để dễ dàng quản lý.
</Callout>
