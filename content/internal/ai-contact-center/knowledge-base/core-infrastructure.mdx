Bảng tra cứu IP Core hạ tầng đầu số ODS dùng khi triển khai đấu nối đầu số (SIP Trunk) từ các nhà mạng viễn thông về hệ thống tổng đài ODS:

---

## 1. Bảng IP Core ODS theo nhà mạng

| Nhà mạng (Telco) | IP WAN Core ODS | Port SIP |
|---|---|:---:|
| **FPT (Đầu 1900)** | `112.78.0.22` | `5060` |
| **FPT (Đầu cố định)** | `112.78.0.25` | `5060` |
| **VNPT (Khu vực HCM)** | `14.225.162.60` | `5060` |
| **VNPT (Khu vực HN)** | `14.225.68.156` | `5060` |
| **VIETTEL** | `112.78.0.23` | `5060` |
| **MOBIFONE** | `112.78.0.24` | **`51000`** |
| **ITEL** | `112.78.0.26` | `5060` |
| **CMC** | `112.78.0.26` | `5060` |
| **GTEL** | `112.78.0.52` | `5060` |

| **SPT** | `112.78.0.20` | `5060` |

---

## 2. Lưu ý kỹ thuật

- **Port kết nối SIP**: Các nhà mạng dùng port chuẩn `5060`, riêng **Mobifone sử dụng port `51000`**.
- **Thủ tục Whitelist IP**: Cung cấp đúng IP Core ODS theo nhà mạng để Telco whitelist IP Signaling & Media (RTP).
